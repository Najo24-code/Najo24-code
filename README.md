### Por qué esto

- Deployo por `git push` directo al servidor, con rebuild automático.
- Blue-green en lo crítico para no tumbar producción.
- Smoke test y curl al healthcheck en cada deploy. Si algo sale rojo, se revierte.
- 2 hosts Proxmox, VMs, Tailscale para la red.
- Soy junior y lo asumo: aprendo rompiendo cosas mías (y arreglándolas).
